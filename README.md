# Dialogue Editor

Editor visuale per creare dialoghi per videogiochi.

## Funzionalità
- Gestione multi-atto
- Personaggi riutilizzabili
- Battute multiple per dialogo
- Scelte con collegamento tra dialoghi
- Preview della conversazione
- Import/export JSON
- Autosalvataggio

## Avvio
\`\`\`bash
npm install
npm run dev
\`\`\`

## Build
\`\`\`bash
npm run build
\`\`\`
